# 數卡整除挑戰

學生網站由 GitHub Pages 發布。自由練習在瀏覽器中運作；老師派發比賽、狀態控制及學生答案由現有比賽服務保存。

- 五張數卡，組成三位數或四位數。
- 自由練習：分為單一條件及雙條件模式，從 2、3、5、10 中選一項或兩項條件，找出全部同時符合條件的數字；顯示本回合完整答案數量及剩餘數量。
- 老師比賽：同時符合兩項整除條件，每場提交三個不同答案。
- 三層提示、即時答案檢查、老師查看全班進度。

## 開發與發布

使用 Node.js 22 或更新版本。執行 `npm install`，再執行 `npm run build`，並提交產生的 `docs/`。GitHub Pages 使用 `main` 分支的 `/docs` 資料夾。

`lib/types.ts` 中的 `API_BASE` 是公開比賽服務網址。瀏覽器只保存參賽憑證；題目、老師設定和作答紀錄由服務的資料庫保存。老師控制台位於 `teacher/`，以老師密碼登入；密碼只在伺服器驗證，GitHub 原始碼和編譯檔不含密碼。登入有效期為 8 小時，登出會撤銷登入憑證。
