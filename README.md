# 數卡整除挑戰

學生網站由 GitHub Pages 發布。自由練習在瀏覽器中運作；老師派發比賽、狀態控制及學生答案由現有比賽服務保存。

- 五張數卡，組成三位數或四位數。
- 自由練習：被 2、3、5 或 10 整除。
- 老師比賽：同時符合兩項整除條件，每場提交三個不同答案。
- 三層提示、即時答案檢查、老師查看全班進度。

## 開發與發布

使用 Node.js 22 或更新版本。執行 `npm install`，再執行 `npm run build`，並提交產生的 `docs/`。GitHub Pages 使用 `main` 分支的 `/docs` 資料夾。

`lib/types.ts` 中的 `API_BASE` 是公開比賽服務網址。瀏覽器只保存參賽憑證；題目、老師設定和作答紀錄由服務的資料庫保存。老師控制台使用老師的 ChatGPT 帳戶登入。
